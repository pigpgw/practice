**문제 7개 + 개념 정리 4개.** 번호가 곧 풀 순서입니다.

## 실제 시험 정보

- 시험일: 2026-10-22(목) 13:00 ~ 17:00 (프로그래밍 테스트 약 2시간 + 다중 면접 약 1시간)
- Visual Studio 기반 PC, C++ 권장 (Python 등 다른 언어 사용 가능)
- 총 6문제 + 회로 관련 보너스 문제
- 약 2시간
- 인터넷 검색 가능, AI 도구 사용 불가
- 배점: 100점 만점. 1~4번은 낮은 배점(비트 5~10점), 5·6번은 고배점(각 20~30점)
- 5번은 CSV 변환, 6번은 로그 파싱 유형
- 합격 기준: 60점 이상, 부분점수와 풀이 과정이 중요
- 전형 비중(지윤특강 기준): 코딩테스트 80%, 면접 20%

## Python 문제

`python_study/exam_practice/` 아래에 7개가 있습니다.

> **이미 풀었던 문제(비트 연산 / 문자열 분리 / CSV 변환 / ASCII / 로그 파싱 / 레지스터 명령)는
> 워크북에서 뺐습니다.** 구현이 끝났거나 중간까지 온 것들이라 다시 볼 필요가 없습니다.

**번호가 곧 풀어야 할 순서입니다.** 01번부터 쭉 풀면 됩니다.
각 문제 docstring에 `## 풀이 순서 (⏱ N분)` 절이 있어서 지금 몇 단계인지 보입니다.

| # | 난이도 | 시간 | 제목 | 커버하는 실전 유형 |
|---|---|---|---|---|
| **01** | 중상 | 40분 | 장비 로그 시간 정렬 및 필터 | **실전 6번 (고배점)** |
| **02** | 중 | 25분 | 회로 계산: 저항 네트워크와 전압 분배 | 회로 보너스 |
| **03** | 중상 | 15분 | 디버깅: 숫자 정렬과 평균 계산 오류 | **실전 2·3번 (디버깅)** |
| **04** | 중상 | 15분 | 디버깅: CSV 파싱과 반올림 오류 | **실전 5번 (고배점) + 디버깅** |
| **05** | 중 | 30분 | 고정 크기 링 버퍼 | 실전 4번 (파일 입출력) |
| **06** | 중상 | 35분 | 메모리 테스트 패턴 생성 | 실전 1번 (비트 연산) + 회로 보너스 |
| **07** | 중상 | 35분 | 웨이퍼 테스트 결과 집계와 수율 | **실전 5번 (CSV 집계)** |

- **03·04번은 "고치는 문제"** 입니다. 코드가 이미 들어 있고 버그가 2~3개 심어져 있습니다.
- 나머지는 "짜는 문제"입니다. 각 `.py` 파일 docstring에 **이 문제가 뭘 하는 건지(## 핵심)**,
  처리 규칙, 입출력 예시, 실행 방법이 들어 있습니다.
  별도의 문제지 파일 없이 각 `.py` 파일만으로 문제를 읽고 풀 수 있습니다.
- `input*`은 문제별 입력 파일입니다.

## 시험장 전략

- 실제 고배점 5·6번에 해당하는 CSV 변환·로그 파싱을 우선 연습한다.
- 1~4번은 비트, 문자열/파일, CSV, 로그 파싱 순서로 기본기를 확인한다.
- 못 풀어도 모든 문제에 손을 대고, 풀이 과정을 종이에 빼곡히 적는다.
- 비트 문제는 검색·계산기 없이 손으로 계산하는 연습을 한다.
- 파일 입출력 문제는 실행 경로와 출력 파일 위치를 먼저 확인한다.
- 뒤쪽 2문제(5·6번)에 시간을 몰아쓴다. 1~4번만 풀어도 60점은 나온다.

## 우선순위

1. **01번 — 실전 6번 고배점 유형(로그 파싱)** — 40분

5. **06·07번 — 패턴(비트 연산) / 웨이퍼 집계(CSV)** — 각 35분
