# practice

테라다인 Memory FAE 코딩테스트 대비 파이썬 연습 문제 모음입니다.
문제 23개 + 개념 정리 4개, 난이도순으로 배치했고 번호가 곧 풀 순서입니다.

## 실제 시험 정보

- 시험일: 2026-10-22(목) 13:00 ~ 17:00 (프로그래밍 테스트 약 2시간 + 다중 면접 약 1시간)
- Visual Studio 기반 PC, C++ 권장 (Python 등 다른 언어 사용 가능)
- 총 6문제 + 회로 관련 보너스 문제
- 약 2시간
- 인터넷 검색 가능, AI 도구 사용 불가
- 배점: 100점 만점. 1~4번은 낮은 배점(비트 5~10점), 5·6번은 고배점(각 20~30점)
- 5번은 CSV 변환, 6번은 로그 파싱 유형
- 합격 기준: 60점 이상, 부분점수와 풀이 과정이 중요
- 전형 비중(지윤특강 기준): 코딩테스트 80%, 면접 20%

| 1 | 32비트 비트 연산 / 테스트 패턴 | 12 (+ 이미 푼 문제) |
| 2 | 단일 객체 메모리 누수 디버깅 | **10** (+03·04·06·07·08·09·21·22·23) |

실제 시험 6문제 중 2문제가 디버깅 유형이었습니다. 그래서 이 워크북에는 디버깅 문제를
10개(03·04·06·07·08·09·10·21·22·23) 따로 모아 뒀습니다.

## Python 문제

`python_study/exam_practice/` 아래에 23개가 있습니다.

> **01~08번은 이미 풀어서 지웠습니다.** (비트 연산 / 문자열 분리 / CSV 변환 = 구현 완료,
> ASCII·로그 파싱 = 중간까지 함, 레지스터 명령 3종 = 예전에 작업하던 06번에서 쪼갠 것)

**번호가 곧 풀어야 할 순서입니다.** 01번부터 쭉 풀면 됩니다.
각 문제 제목에 `(N단계 · 난이도 …)` 이 붙어 있어서 지금 몇 단계인지 보입니다.

| 단계 | 문제 | 내용 |
|---|---|---|
| **1단계** | 01·02·03 | 실전 고배점 2종(로그 파싱) + 회로 계산 |
| **2단계** | 04~10 | 디버깅 7문제 (각 15분, 점수 올리기 제일 빠름) |
| **3단계** | 11·12 | 링 버퍼, ATE 패턴 벡터 |
| **4단계** | 13~18 | 로그 파싱 상급 (SCPI, 고객 로그, 상태 머신, 매칭) |
| **5단계** | 19~24 | 집계·판정 (실전 5번 CSV 유형) |
| **6단계** | 25~28 | 바이너리 + 남은 디버깅 3문제 |

각 `.py` 파일의 docstring에 **이 문제가 뭘 하는 건지(## 핵심)**, 입력·출력 예시, 실행 방법이
들어 있습니다. 별도의 문제지 파일 없이 각 `.py` 파일만으로 문제를 읽고 풀 수 있습니다.
`input*`은 문제별 입력 파일입니다.

## 시험장 전략

- 실제 고배점 5·6번에 해당하는 CSV 변환·로그 파싱을 우선 연습한다.
- 1~4번은 비트, 문자열/파일, CSV, 로그 파싱 순서로 기본기를 확인한다.
- 못 풀어도 모든 문제에 손을 대고, 풀이 과정을 종이에 빼곡히 적는다.
- 비트 문제는 검색·계산기 없이 손으로 계산하는 연습을 한다.
- 파일 입출력 문제는 실행 경로와 출력 파일 위치를 먼저 확인한다.
- 뒤쪽 2문제(5·6번)에 시간을 몰아쓴다. 1~4번만 풀어도 60점은 나온다.

## 우선순위

1. **01번 — 실전 6번 고배점 유형(로그 파싱)**

5. **나머지 — 디버깅 5개, 패턴, 집계·판정, 바이너리**
