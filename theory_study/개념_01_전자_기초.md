# 전자 기초 — 회로를 보기 위한 최소 지식

코딩 문제 01(비트 연산) 직전에 보는 곳이다. 모르는 건 답만 보고 넘어가도 된다.

---

## 1. 전압, 전류, 저항

- **전압(V)**: 두 점 사이의 전위차. 전하가 흐르려는 힘의 크기. 단위 V.
- **전류(I)**: 단위 시간당 흐르는 전하량. 단위 A. `I = Q / t`.
- **저항(R)**: 전류 흐름을 방해하는 정도. 단위 Ω.

옴의 법칙 `V = I × R`이랑 같이 기억하면 된다. 저항이 일정하면 전압과 전류가 비례한다.

테스트 프로그램에서 "이 신호에 2.5V를 인가한다", "이 핀에서 10mA가 흐른다" 같은 스펙을
회로에 그대로 대응시키는 일이라 익숙해둘 필요가 있다.

## 2. 직렬과 병렬

- **직렬**: 전류가 전부 같다(분기 없음). 합성 저항 `R = R1 + R2 + ...`
  - 100Ω + 220Ω = 320Ω
- **병렬**: 전압이 전부 같다. 합성 저항 `1/R = 1/R1 + 1/R2 + ...`
  - 100Ω ∥ 100Ω = 50Ω, 1kΩ ∥ 1kΩ ∥ 500Ω = 250Ω

코딩 문제 09번(회로 계산)이 이거 그대로다.

## 3. 전압 분배와 전류 분배

```
Vin ── R1 ──┬── R2 ── GND
            └── Vout
```

- `Vout = Vin × R2 / (R1 + R2)`
- `V1 = Vin × R1 / (R1 + R2)` (R1 쪽에 걸리는 전압)
- 전류 `I = Vin / (R1 + R2)`

ATE 테스트 보드에서 DUT 핀에 인가하는 레벨을 만들 때 쓰는 계산이다.

## 4. 풀업 / 풀다운

신호선에 아무것도 연결되지 않으면 그 라인은 **플로팅(floating)** 상태가 돼서 값이
들쭉날쭉하다(잡음에 따라 0인지 1인지 모름). 그래서 저항 하나로 전원이나 접지에 묶어
기본 상태를 정해 둔다.

- **풀업**: 저항을 VCC 쪽에 연결 → 기본 상태 **HIGH**
- **풀다운**: 저항을 GND 쪽에 연결 → 기본 상태 **LOW**

DUT 핀 상태를 읽을 때, I2C 버스, 리세트 신호가 전부 풀업이다.
테스트할 때 "이 신호가 HIGH인가?"를 물으면 여기서 답이 나온다.

## 5. DIO — Push-pull 과 Open-drain

| | Push-pull | Open-drain |
|---|---|---|
| HIGH | 능동으로 밀어 올림 | **풀업 저항에 의존** |
| LOW | 능동으로 끌어 내림 | 능동으로 끌어 내림 |
| 선을 공유 | 못 함(충돌 위험) | 가능 (wired-AND) |

I2C, SMBus 같은 2선식 버스는 open-drain이다. 여러 Devices가 한 선을 공유하므로 HIGH를
능동으로 밀면 서로 부딪힌다. 그때 "누가 HIGH인지" 찾는 게 디버깅 단골이다.

## 6. MOSFET

전류로 제어되는 스위치다. BJT(전류 제어)와 달리 **게이트 전류가 거의 없어서** 전력 소모가 적다.

- **NMOS**: 게이트에 HIGH(VDD) 주면 ON. 저항성 스위치로 동작.
- **PMOS**: 게이트에 LOW(VSS) 주면 ON. NMOS와 반대로 동작.
- CMOS 인버터: NMOS + PMOS를 직렬로 붙여 `0 → 1`, `1 → 0`을 만든다.

클록 게이트, 셀 어레이의 word line 선택이 다 MOSFET 스위치다. DRAM 셀의 워드라인도 이거다.

## 7. 타이밍 — Setup / Hold

- **Setup time**: 클록 엣지 **전**에 데이터가 안정적으로 유지돼야 하는 최소 시간
- **Hold time**: 클록 엣지 **후**에 데이터가 유지돼야 하는 최소 시간

둘 다 어기면 플립플롭이 엉뚱한 값을 잡는다. 클록이 빨라질수록 여유가 줄어든다.

메모리 테스트에서 클록 주파수를 올려 타이밍 스트레스를 보는 테스트가 있고,
실패하면 "칩 문제"가 아니라 "테스트 조건 문제"다.

## 8. 신호 무결성 — 반사와 크로스토크

- **반사(Reflection)**: 발신 임피던스와 수신 임피던스가 다르면 신호가 되돌아온다.
  흔한 예는 50Ω 동축 케이블에 종단저항(termination)을 안 단 경우.
- **크로스토크(Crosstalk)**: 인접한 신호선끼리 간섭. 선 간격이 좁거나 ground가 부실하면.
  보통 **공통 경로(공통 임피던스)를 currentsharing** 한 부분에서 생긴다.

대처는 임피던스 매칭, 종단저항, 선 간격 넓히기, grounding 강화, shield.

고속 테스트에서 "가끔 값이 틀린다"는 이슈의 1순위가 임피던스 불일치다.
FAE가 이걸 바로 짚어내는 게 실력이다.

## 9. 전원

- `VCC` / `VDD`: 전원 레일(rail). 칩 안 회로에 공급되는 전압.
- `VSS` / `GND`: 접지 레일. 기준 전위(0V).
- **디커플링 커패시터**: 전원 핀 근처에 붙이는 작은 캐패시터. 전원 라인에 순간적인
  전류 변화(스위칭 노이즈)가 생기면 전압이 흔들리는 걸 잡아준다.

테스트 보드에서 "이 핀에 전원을 인가"할 때 어디에 걸지, 리턴 경로는 어디로 잡는지가
실제 하드웨어 문제의 절반이다.
