# 회로 계산 — 숫자로 해보기

코딩 문제 02번(회로 계산)을 풀기 전에 보는 곳이다.
"이 보드 회로 좀 봐주세요"가 나왔을 때 필요한 최소 계산 능력만 정리했다.
마지막에 연습 문제 5개가 있다.

---

## 1. 기본 세 가지

5V를 100Ω에 걸면:

- `I = V / R = 5 / 100 = 0.05 A = 50 mA`
- 저항 양쪽 전압은 5V 전체.

1.2V를 300Ω에 걸면 `I = 1.2 / 300 = 0.004 A = 4 mA`.

## 2. 직렬

100Ω와 220Ω를 직렬로 연결하고 5V를 걸면:

- `Rtotal = 100 + 220 = 320Ω`
- `I = 5 / 320 = 0.015625 A`
- `V1 = 0.015625 × 100 = 1.5625 V`
- `V2 = 0.015625 × 220 = 3.4375 V`

확인은 `1.5625 + 3.4375 = 5.0 V`로 한다. 안 맞으면 계산 실수다.
코딩 문제 02번의 예시가 이 계산이다.

## 3. 병렬

1kΩ, 1kΩ, 500Ω를 병렬로 연결하면:

```
1/R = 1/1000 + 1/1000 + 1/500 = 0.001 + 0.001 + 0.002 = 0.004
R = 1 / 0.004 = 250Ω
```

두 저항만 병렬이면 `R = R1 × R2 / (R1 + R2)`다. 100Ω ∥ 100Ω = 50Ω, 100Ω ∥ 220Ω = 68.75Ω.

병렬은 저항값이 **작아지고**, 직렬은 **커진다**.

## 4. 전압 분배기

5V를 R1 = 1kΩ, R2 = 2kΩ로 나눠서 가운데 전압은:

- `Vout = Vin × R2 / (R1 + R2) = 5 × 2000 / 3000 = 3.3333 V`
- `V1 = 5 × 1000 / 3000 = 1.6667 V`
- `V2 = 3.3333 V`

분배기는 **출력 저항**이 있어서 전류를 흘리면 값이 떨어진다.
정확한 전압이 필요하면 **버퍼(-op amp)**를 쓴다.

## 5. 풀업 저항과 LED

3.3V 시스템에서 5.1kΩ 풀업에 LED(R = 20Ω)를 붙이면:

```
전체 저항 = 5100 + 20 = 5120Ω
I = 3.3 / 5120 = 0.000644 A = 0.644 mA
```

LED 전류를 정할 때 저항값을 이렇게 잡는다. 0.644 mA면 눈으로 약간 보인다.

## 6. RC 시상수

10kΩ와 100nF를 걸면:

```
τ = R × C = 10000 × 100e-9 = 1e-3 s = 1 ms
```

시상수 5배(5τ)면 practically settled(99.3% 도달)다.
RC는 **로우패스 필터**가 되고, 커패시터를 병렬로 붙이면 하이패스가 된다.

테스트 보드에서 신호 shaping, debounce, 전원 ON ramp 에서 본다.

## 7. 종단저항과 반사

50Ω 라인에 50Ω 종단을 안 달면:

- 발신측 50Ω, 수신측 high-Z(∞) → 반사 계수 `(Z_L - Z_0)/(Z_L + Z_0) = 1` → 완전 반사.
- 종단 50Ω 달면 반사 계수 0.

고속 신호에서 반사가 오면 setup/hold 위반으로 보인다. "값이 가끔 이상하다"는 이슈의
직접 원인이다.

## 8. 크로스토크

인접 신호가 서로 간섭하는 이유:

- 인접 두 선이 **공통 저항(공통 임피던스)**을 공유하는데, 한 선에 전류가 흐르면 그 전류가
  공통 저항에 전압을 만들어 옆 선에 간섭이 생긴다.
- 대처: **선 간격 넓히기**, **사이에 ground 넣기**, **ground plane**, **차폐(cable shield)**,
  저속 신호면 **시리얼 저항**(source termination)으로 전류를 줄여서.

## 9. 타이밍 계산

클록 100MHz(=10ns 주기)에 setup time 2ns, hold time 1ns면:

- 데이터는 클록 엣지 **2ns 전**부터 안정, **엣지 후 1ns**까지 유지.
- 두 신호가 같은 클록에 맞춰야 한다면 데이터 경로 지연 차이가 setup+hold 안에 들어와야 한다.
- 클록 주기가 10ns인데 여유가 3ns밖에 없으면 보드 배치가 곧 스펙이 된다.

메모리 클록을 올려 스트레스 테스트를 돌릴 때, 실패하면 칩 문제인지 보드 문제인지
이 계산으로 갈린다.

## 연습 문제 (답은 눌러서 확인)

**P1.** 12V를 330Ω과 470Ω 직렬에 걸었을 때 각 저항의 전압은? (소수 둘째 자리)

<details><summary>답</summary>

- Rtotal = 800Ω, I = 12/800 = 0.015 A
- V(330) = 4.95 V, V(470) = 7.05 V
</details>

**P2.** 10kΩ과 10kΩ을 병렬로 연결한 저항은? 100Ω과 50kΩ을 병렬로 연결하면?

<details><summary>답</summary>

- 10k ∥ 10k = 5kΩ
- 100 ∥ 50k = `100 × 50000 / 50100` = 99.8Ω
</details>

**P3.** 24V를 R1 = 12kΩ, R2 = 12kΩ로 나눴을 때 가운데 전압은?

<details><summary>답</summary>

- 12V (절반씩)
</details>

**P4.** 5V에 1kΩ 저항과 LED(R=20Ω)를 직렬로 연결했을 때 LED 전류는? LED 양극 전압은 2V라고 하면?

<details><summary>답</summary>

- LED가 2V를 먹으므로 저항에 남는 전압은 3V
- I = 3 / 1000 = 3 mA
</details>

**P5.** 1kΩ과 1µF RC의 시상수는? 5τ는 몇 ms?

<details><summary>답</summary>

- τ = 1000 × 1e-6 = 1 ms, 5τ = 5 ms
</details>
