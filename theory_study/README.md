# 개념 학습 — 전자 → 반도체 → 회로 → C++

코딩 문제 28개를 다 푸는 것만으로는 부족하다. 이 폴더는 그 옆에 끼워 넣는 개념 공부 순서다.

개념은 섞지 않고 순서대로 깊게 간다. 전자 → 반도체 → 회로 → C++는 서로 발이 걸린
내용이라서 섞어두면 매번 새 개념을 떠올리는 데 에너지를 쓰게 된다.
개념은 묶어서 깊게, 코딩은 그 사이사이에.

## 전체 로드맵

```
── Phase 1 : 전자 기초 + 파일 입출력 기본기 ─────────────
  [개념_01_전자_기초.md]      전압·전류·저항, 직렬/병렬, 풀업, DIO, MOSFET, 타이밍
  01 비트 연산
  02 문자열 분리 후 파일 저장
  03 장비 측정 결과 CSV 변환        ← 실제 시험 5번 유형
  04 ASCII 조건 변환

── Phase 2 : 반도체/메모리 + 로그 파싱 ──────────────────
  [개념_02_반도체_메모리.md]      웨이퍼/파이널 테스트, RA, DRAM/NAND/HBM
  05 장비 검사 로그 파싱 및 변환    ← 실제 시험 6번 유형
  06 레지스터 명령 해석기
  07 다중 사이트 로그 분석
  08 고정 크기 링 버퍼
  09 회로 계산

── Phase 3 : 회로 계산 + 실전 업무 데이터 ───────────────
  [개념_03_회로_계산.md]          전압분배, RC, 종단저항, 크로스토크, 연습문제
  10 Lot별 결과 요약
  11 SCPI 명령 처리기
  12 디버깅: 숫자 정렬과 평균
  13 바이너리 데이터로그 파서
  14 웨이퍼 테스트 결과 집계
  15 디버깅: 인덱스 범위와 누수
  16 장비 로그 시간 정렬 및 필터
  17 디버깅: 파일 핸들 누수
  18 리페어(RA) 전후 수율 비교
  19 디버깅: CSV 파싱과 반올림

── Phase 4 : 고급 업무 + C++ 읽기 ───────────────────────
  20 고객 로그 파싱·이슈 묶기
  21 테스트 실행 상태 머신
  22 Site/Test별 통계와 Cpk
  23 명령/응답 로그 상관
  24 디버깅: 그룹 집계와 출력 순서
  25 테스트 플랜 실행과 Bin 판정
  26 ATE 테스트 패턴 벡터
  [개념_04_C++_개념.md]           new/delete, vector, RAII, 파일 I/O, 오버플로
```

- 개념 4개는 각각 10~13개 질문으로 되어 있다. 답을 보고 소화하면 된다.
- 개념_03(회로 계산)에 연습 문제 5개가 있다. 직접 풀어보고 09번이랑 결과를 맞춰본다.
- 개념_04(C++)는 **코드를 짜는 게 아니라 읽는 법**이다. Python으로 준비할 거라
  읽기만 할 줄 알면 충분하다.
