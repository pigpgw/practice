# 개념 학습 — 전자 → 반도체 → 회로 → C++

코딩 문제 7개를 다 푸는 것만으로는 부족하다. 이 폴더는 그 옆에 끼워 넣는 개념 공부 순서다.

개념은 섞지 않고 순서대로 깊게 간다. 전자 → 반도체 → 회로 → C++는 서로 발이 걸린
내용이라서 섞어두면 매번 새 개념을 떠올리는 데 에너지를 쓰게 된다.
개념은 묶어서 깊게, 코딩은 그 사이사이에.

---

## 전체 로드맵

```
── Phase 1 : 전자 기초 ─────────────────────
  [개념_01_전자_기초.md]      전압·전류·저항, 직렬/병렬, 풀업, DIO, MOSFET, 타이밍
  → 코딩 02번 회로 계산

── Phase 2 : 반도체/메모리 ──────────────────
  [개념_02_반도체_메모리.md]      웨이퍼/파이널 테스트, RA, DRAM/NAND/HBM
  → 코딩 01번 로그 시간 정렬
  → 코딩 06번 메모리 테스트 패턴
  → 코딩 07번 웨이퍼 테스트 결과 집계

── Phase 3 : 회로 계산 + 실전 업무 데이터 ──
  [개념_03_회로_계산.md]      전압분배, RC, 종단저항, 크로스토크, 연습문제 5개
  → 코딩 02번 회로 계산 (수식이 이미 다 나온다)

── Phase 4 : C++ 읽기 ─────────────────────
  [개념_04_C++_개념.md]       new/delete, vector, RAII, 파일 I/O, 오버플로
  → 코딩 03·04번 디버깅 (실전 2·3번이 C++ 메모리 누수 디버깅이다)
```

- 개념 4개는 각각 9~13개 질문으로 되어 있다. 답을 보고 소화하면 된다.
- 개념_03(회로 계산)에 연습 문제 5개가 있다. 직접 풀어보고 02번이랑 결과를 맞춰본다.
- 개념_04(C++)는 **코드를 짜는 게 아니라 읽는 법**이다. Python으로 준비할 거라
  읽기만 할 줄 알면 충분하다.
