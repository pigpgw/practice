# 학습 체크리스트 — 23문제 로드맵

시험은 6문제 + 회로 보너스, 2시간입니다.

> **번호가 곧 풀 순서입니다.** 01번부터 쭉 풀면 됩니다.
> 01~05번이 **2시간 플랜**이고, 그 뒤는 난이도순(06~15 중상, 16~23 상)입니다.
>
> **각 문제 docstring의 `## 풀이 순서 (⏱ N분)` 절**에 단계별 시간 배분이 있습니다.
> 거기서 끊고 넘어가세요.

>

### 2시간 동안 손댈 공통 준비 (5분)

- `fmt()` 헬퍼를 만들어둡니다 (사사오입 한 줄)
  ```python
  def fmt(value, places="0.01"):
      return f"{Decimal(str(value)).quantize(Decimal(places), rounding=ROUND_HALF_UP):.2f}"
  ```
- VS Code 자동 정렬 켜두기 (Cmd+S → 정렬)
- 타이머 켜고 시작 (문제당 시간 배분 엄수)

## 디버깅 문제 풀이법 (03·04·06~10 · 21~23)

코드가 이미 들어 있고 **고치는** 문제다.

1. **먼저 돌려서 증상을 본다.** 어떤 에러가 나는지, 출력이 어떻게 이상한지.
2. **입력 → 처리 → 출력 순서로 훑는다.** 어디서 상태가 안 맞는지 찾는다.
3. **한 줄씩 고친다.** 한 번에 여러 군데를 고치면 뭐가 효과가 있었는지 모른다.
4. **고친 이유를 한 줄씩 적는다.** (면접관이 본다)
5. **증상이 사라졌는지 확인한다.**

심어둔 버그 목록은 `공통_규칙.md` 6절에 표로 정리돼 있습니다.

## 학습 루틴

### 매번 공통
1. **먼저 문제지를 3분 안에 읽고 계획한다.** 입출력 형식, 오류 규칙, 반올림 규칙을 손에 적는다.
2. **풀이 과정을 손으로 적는다.** (면접관이 본다)
   - 입력 구조 → 처리 순서 → 출력 형식 → 예외 처리 순서
3. 코드를 한 번에 쓰지 말고 입력 → 처리 → 출력 3단으로 나눠 쓴다.
4. 실행 후 예시 출력과 한 줄씩 diff 한다.
5. 틀린 건 "왜 틀렸는지" 한 줄 적고 넘어간다.

### 파일 입출력 체크리스트 (매번)
- [ ] 실행 디렉터리가 문제 파일 위치인가
- [ ] 입력/출력 파일 이름이 맞는가
- [ ] 줄바꿈이 `\n` 으로만 되어 있는가, 마지막 줄에도 있는가
- [ ] 소수 자릿수가 규칙대로인가 (`25.00`, `1.00`)
- [ ] 헤더 줄을 정확히 넣었는가 / 안 넣었는가
- [ ] 요약 줄을 화면에 냈는가, 파일에 냈는가

### 반올림 체크리스트 (매번)
- [ ] `round()` 가 아니라 `Decimal` + `ROUND_HALF_UP`
- [ ] `InvalidOperation` 을 `ValueError` 로 변환했는가 (traceback 방지)
- [ ] 평균/합의 시작값이 Decimal 인가 (`sum(vals, Decimal("0"))`)

### 시뮬레이션
- 2시간 타이머, 6문제 (`python3 연습순서.py 6`)
- 1~4번에 40분, 5·6번에 60분, 20분 여유
  (친구 후기: 뒤쪽 2문제에 1시간 30분 씀. 60점은 1~4번만 풀어도 가능)
- **못 푸는 문제는 빈칸으로 두지 말고** 풀이 과정을 빼곡히 적는다
- 채점은 **결과 파일 비교**라서, 부분점수를 노린다면 최소한 파일은 만들어져야 한다
